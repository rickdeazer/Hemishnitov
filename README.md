## 🛠️ Getting Started

Follow these steps to set up MMUN on your local machine for development and testing.

### Prerequisites
Make sure you have the following installed:
* [Node.js (v18 or higher)]
* [Git]
* [VScode]

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com[Your-GitHub-Username]/[Your-Repo-Name].git
   cd [Your-Repo-Name]
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment variables**
   * Copy the example environment file:
     ```bash
     cp .env.example .env
     ```
   * Ask the repository owner for the development API keys and add them to `.env`.

4. **Run the application**
   ```bash
   npm start
   ```

## 🤝 How to Contribute

We welcome approved developers to help build MMUN! To keep the codebase clean and protect project ownership, please follow these rules:

1. **Sign the Contributor License Agreement (CLA):** By submitting code to MMUN, you agree to the terms in [CLA.md](CLA.md), which assigns full copyright and ownership of your code contributions to the project owner. Also ensure you've signed an enrollment as a devopment @ https://mmun.rickdeazer.com/specialists/applications
2. **Create a feature branch:** Never push directly to `main` or `master` branches. Create a new branch for your task:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit your changes:** Write clear, descriptive commit messages.
4. **Open a Pull Request (PR):** In your PR description, include the statement:  
   *"I have read and agree to the terms of CLA.md."*
